# Salt & Stone — сайт с онлайн-записью и админ-панелью

Стек: **Node.js + Express** (бэкенд), статический HTML/CSS/JS (фронтенд), записи хранятся в `data/bookings.json`.

## Структура проекта

```
massage-booking/
├── server.js          — сервер Express: API /api/slots, /api/book и защищённое /api/admin/*
├── package.json
├── .env.example        — шаблон переменных окружения (скопировать в .env)
├── data/
│   └── bookings.json  — "база данных" записей (JSON-файл)
├── public/
│   └── index.html      — сайт с формой онлайн-записи
└── admin/
    └── index.html      — админ-панель: список записей, отмена записи
```

## 1. Установка

Понадобится **Node.js 18 или новее**.

```bash
cd massage-booking
npm install
```

## 2. Настройка админ-панели

Скопируйте `.env.example` в `.env`:

```bash
cp .env.example .env
```

Откройте `.env` и задайте логин/пароль для входа в админку:

```
ADMIN_USER=admin
ADMIN_PASSWORD=ваш-надёжный-пароль
```

Без `ADMIN_PASSWORD` сайт с записью будет работать, но `/admin` вернёт ошибку 503 — это осознанная защита, чтобы админка не осталась открытой со стандартным паролем.

## 3. Запуск

```bash
npm start
```

- Сайт с записью: `http://localhost:3000`
- Админ-панель: `http://localhost:3000/admin` — браузер спросит логин/пароль (те, что вы задали в `.env`)

## Как это работает

- **Слоты времени** заданы в `server.js` в массиве `SLOTS` (сейчас 10:00–20:00 с шагом в час) — поменяйте список под свои реальные часы работы.
- При выборе даты фронтенд запрашивает `GET /api/slots?date=YYYY-MM-DD` — сервер смотрит `data/bookings.json` и помечает уже занятые часы как `booked: true`. Занятые слоты рисуются серыми и недоступны для клика.
- При отправке формы фронтенд шлёт `POST /api/book`. Сервер **повторно проверяет** на бэкенде, что слот всё ещё свободен (это защищает от двойной записи, даже если два человека открыли сайт одновременно), и сохраняет запись в `data/bookings.json`.
- **Админ-панель** (`/admin`) защищена HTTP Basic Auth — показывает все записи (дата, время, имя, телефон, когда создана запись), даёт фильтровать по дате и отменять записи кнопкой «Отменить» (слот сразу освобождается для новых броней).

## Куда загрузить свои фото

В `public/index.html` найдите строки `<img src="https://images.unsplash.com/...">` и замените ссылку на путь к своему файлу — например, положите фото в `public/images/` и укажите `src="images/moyo-foto.jpg"`.

## Как разместить сайт в интернете (не только на localhost)

Этому сайту нужен постоянно работающий сервер (не статический хостинг), поэтому подойдут, например:

- **Railway**, **Render** или **Fly.io** — подключаете репозиторий, задаёте переменные `ADMIN_USER` и `ADMIN_PASSWORD` в настройках проекта, и они сами запускают `npm start`.
- Обычный VPS (например, DigitalOcean, Timeweb) — загружаете файлы, ставите Node.js, настраиваете `.env`, запускаете через `pm2` или `systemd`, чтобы сервер не останавливался.

Важно: `data/bookings.json` хранит записи локально на сервере. Если хостинг пересоздаёт файловую систему при каждом деплое (как некоторые бесплатные тарифы), записи могут теряться — в таком случае стоит перейти на настоящую базу данных (например, SQLite или Postgres), когда проект вырастет.
