# Salt & Stone — сайт с онлайн-записью и админ-панелью

Стек: **Node.js + Express** (бэкенд), статический HTML/CSS/JS (фронтенд), записи хранятся в базе **PostgreSQL** (Neon) — или в JSON-файлах, если база не задана.

## Что умеет сайт

- **Онлайн-запись** каждый день с 10:00 до 20:00 (сеансы по часу, последний — 19:00–20:00). Нельзя записаться на прошедшее время, меньше чем за час и дальше чем на 60 дней вперёд.
- **Услуги и цены** — отдельный блок на странице; кнопка «Записаться» на карточке сразу выбирает услугу в форме.
- **Три языка: русский, английский, грузинский.** Язык выбирается автоматически по языку телефона, его можно сменить кнопками RU / EN / KA. Ссылка с `?lang=en` (или `ru`, `ka`) открывает сайт сразу на нужном языке — удобно для Instagram и Google.
- **Плавающая кнопка WhatsApp** с готовым текстом на языке посетителя.
- **После записи:** «Добавить в календарь» (файл .ics и Google Календарь, с напоминанием за 2 часа) и ссылка для **отмены записи самим клиентом** — не позже чем за 3 часа до сеанса. Об отмене приходит уведомление в Telegram.
- **«Ваши записи на этом устройстве»** — клиент видит свои будущие записи и может открыть календарь или отменить.
- **Уведомления в Telegram** о каждой новой записи и отмене + **утренняя сводка** записей на день.
- **Админ-панель** `/admin`: все записи (с языком клиента), отмена, блокировка часов или целых дней.

## Настройки (переменные окружения на Render → Environment)

| Переменная | Что это |
|---|---|
| `ADMIN_PASSWORD` | пароль админки (вход: пароль + код из Telegram на все `CHAT_ID`) |
| `ADMIN_2FA` | `off` — запасной вход только по паролю, если Telegram недоступен (обычно не задавать) |
| `BOT_TOKEN`, `CHAT_ID` | Telegram-бот и получатели (несколько — через запятую) |
| `DATABASE_URL` | строка подключения к базе Neon (без неё записи пропадают на бесплатном Render) |
| `TRUST_PROXY` | на Render — `3` (любое число больше 0: сервер доверяет только внутренней сети Render и Cloudflare; проверка: `/api/admin/whoami` показывает ваш настоящий IP) |
| `CRON_SECRET` | секрет для утренней сводки (пусто — сводка выключена) |
| `PUBLIC_URL` | необязательно: адрес сайта для ссылок в календаре |

## Утренняя сводка

Бесплатный Render засыпает, поэтому сводку запускает внешний сервис **cron-job.org**: каждый день в 9:00 он открывает адрес

```
https://ВАШ-САЙТ/api/cron/daily-summary?key=CRON_SECRET
```

Сводка отправляется не больше одного раза в день, поэтому можно (и нужно) поставить несколько попыток подряд — 9:00, 9:05, 9:10: первая будит сервер, следующая гарантированно отправит.

## Где что менять

- **Часы работы** — массив `SLOTS` и `OPEN_TIME`/`CLOSE_TIME` в `server.js` (и строка «10:00 – 20:00» в `public/index.html`).
- **Услуги и цены** — массив `SERVICES` в `server.js` (название по-русски для Telegram и названия на 3 языках для сайта).
- **Тексты и переводы** — `public/i18n.js`.
- **Видео в верхнем блоке** — файлы `public/media/hero.mp4`, `hero.webm` и постер `hero-poster.jpg` (ролик с Pexels, бесплатная лицензия для сайтов). Чтобы заменить — положите свои файлы с теми же именами (MP4 — H.264, без звука, лучше до 3 МБ).

## Безопасность

- Админка: длинный пароль, 5 неудачных попыток с одного IP → блок на 20 минут, уведомление в Telegram при массовом переборе.
- Запись: ловушка для ботов, лимиты по IP, не больше 3 будущих записей на номер, не больше 20 записей в час на весь сайт, защита от двойной записи на одно время.
- Ссылка отмены: случайный ключ 256 бит, в базе хранится только его хеш.
- Content-Security-Policy: браузер выполняет только скрипты с этого сайта; данные клиентов выводятся только как текст (защита от XSS).
- Все запросы к базе параметризованы (защита от SQL-инъекций).

## Запуск на своём компьютере

Понадобится **Node.js 18 или новее**.

```bash
npm install
cp .env.example .env   # и заполните ADMIN_PASSWORD
npm start
```

Сайт: `http://localhost:3000`, админка: `http://localhost:3000/admin`.

## Анимации

Сайт оживлён библиотекой [Anime.js](https://animejs.com) v4.5.0 (лицензия MIT).
Файл библиотеки лежит в `public/vendor/` (а не на чужом CDN — так его разрешает
политика безопасности сайта), все анимации — в `public/animations.js`.
Если библиотека не загрузится, сайт работает как обычно, просто без движения.
Тем, у кого в системе включено «уменьшить движение», показывается только
мягкое появление без сдвигов.

## Вход в админку

`/admin` → страница входа: пароль, затем код из 6 цифр, который приходит в
Telegram (на все `CHAT_ID`). Код действует 5 минут, 5 попыток, только с того
же адреса. 5 ошибок подряд с одного адреса — блокировка на 20 минут.
После входа — защищённая cookie (HttpOnly, Secure, SameSite=Strict) на 12 часов,
без действий — 2 часа. В админке есть «Выйти» и «Выйти на всех устройствах»;
смена `ADMIN_PASSWORD` тоже выкидывает все устройства. О каждом входе
приходит уведомление в Telegram.
